# NexusAI backend (Spring Boot) — integrated Backend A + B

The complete Spring Boot backend: security, auth/users, audit, documents (upload, async ingestion, search proxy), investigations
(background runs, replayable SSE, approvals with a simulated, race-safe executor), memory and eval proxies, dashboard, and the only
Python-aware client (`ai/AiServiceClient`). Flyway V1-V6 are included; **V7 (seed data) is generated by the AI stream**
(`ai-service/app/evals/seed`) and must be copied to `src/main/resources/db/migration/V7__seed_business_data.sql`.

Java 21, Spring Boot 3.5.x, Maven, package-by-feature under `com.nexusai`. Contract: `api-contracts.md` v2.1 (kept in the monorepo's top-level `docs/`, not in this folder) is the law.

## Run
```bash
# 1. Postgres with pgvector (dev)
docker run -d --name nexus-pg -e POSTGRES_DB=nexusai -e POSTGRES_USER=nexus -e POSTGRES_PASSWORD=nexus_dev -p 5432:5432 pgvector/pgvector:pg16
# 2. App (profile dev is the default; dev secrets live only in application-dev.yml)
mvn spring-boot:run            # or ./mvnw spring-boot:run after generating the wrapper (see below)
# optional: ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD='Choose-a-strong-1' mvn spring-boot:run
```
Swagger UI (dev only): http://localhost:8080/swagger-ui.html . Health: `/actuator/health`.

Maven wrapper: generate once with network access: `mvn -N wrapper:wrapper -Dmaven=3.9.9`, then commit `mvnw`, `mvnw.cmd`, `.mvn/`.

## Test
```bash
mvn test        # unit tests only (no Docker): JWT, password policy, file validator, storage, rate limiter, service and executor tests, state machine, catalogue, hub
mvn verify      # + integration tests (*IT) with Testcontainers pgvector/pgvector:pg16 and a WireMock AI stub; needs Docker
```
Integration tests extend `IntegrationTestBase` (Postgres + AI stub + `createUser(Role)` / `sessionFor(Role)` helpers).

## Configuration (env, contract section 11)
See `.env.example`. In prod (`SPRING_PROFILES_ACTIVE=prod`) startup fails if `JWT_SECRET`, `INTERNAL_API_KEY` or `POSTGRES_PASSWORD` is missing or a dev default.

## Docker
`docker build -t nexusai-backend .` (multi-stage, non-root, healthcheck on `/actuator/health`).

## Investigations, approvals and the stream (Backend B)
| Concern | Where |
|---|---|
| Start / list / detail / steps / cancel / feedback / report.md | `investigation/InvestigationController` + `InvestigationService` |
| One background task per run, persists every event with a Spring `seq` | `RunRelayService` (bounded `runRelayExecutor`), `InvestigationEventPersister` (row lock + atomic `last_seq`) |
| Browser SSE: replay from `Last-Event-ID` / `?after`, live tail, `: ping` every 15 s, many viewers | `InvestigationStreamService`, `StreamHub` |
| State machine (RUNNING, AWAITING_APPROVAL, COMPLETED, FAILED, CANCELLED, REFUSED) | `InvestigationStateMachine` |
| Approvals: decide (role + self-approval + comment + conditional UPDATE), expiry | `approval/ApprovalService`, `ApprovalFlowService`, `ApprovalExpiryJob` |
| Simulated actions, risk fixed by catalogue | `ActionCatalogue`, `ActionExecutor` |
| Restart recovery | `InvestigationSweeper` |
| Memory / eval proxies, dashboard | `memory/`, `eval/`, `investigation/DashboardService` |

Metrics (Prometheus, internal network only): `nexus_run_duration_seconds`, `nexus_run_loops`, `nexus_runs_finished_total`, `nexus_approvals_pending`, `nexus_runs_live`, `nexus_ai_errors_total`, `nexus_ingestion_duration_seconds`.

Settings (env): `MAX_CONCURRENT_RUNS_PER_USER` (2), `APPROVAL_TTL_DAYS` (7), `MAX_LOOPS` (3, hard limit 5), `RUN_STREAM_IDLE_TIMEOUT_SEC` (300).

## Extension points
| Need | Use |
|---|---|
| Authenticated caller | `CurrentUser.require()` / `.id()` / `.role()` (`AuthenticatedUser` has `sessionId`) |
| Python calls | one method per internal endpoint in `AiServiceClient`; errors via `execute(...)` / `map(...)` / `mapStreamError(...)` |
| Background runs | `@Qualifier("runRelayExecutor") Executor` (bounded, rejects when full) |
| Audit | `AuditService.record(...)`, `AuditService.approvalDecision(userId, approvalId, "APPROVE"|"REJECT")` |
| Tests | extend `IntegrationTestBase` (A) or `RunTestSupport` (B: SSE script builders, `startRun`, `decide`, `awaitStatus`) |
