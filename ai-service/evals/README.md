# Evaluation data contract

The AI-service implementation is supplied by the parallel AI build. This directory holds reproducibility metadata and CI output contracts only; it does not fabricate scores.

- `baseline_metrics.json` is intentionally `NOT_MEASURED`. Replace the sentinel with real, traceable results after the retrieval-only ablation is implemented. While the sentinel remains, `eval-ci` warns and skips only the regression comparison; every safety check (guardrails, SQL guard, approval-gate compliance, citation validation, fault injection) still gates the build. Format: contract section 13.
- `ci-results.json` must be generated by `python -m app.evals.ci_check` and contain a top-level `status` plus a `metrics` object. The workflow publishes its metrics in the job summary and uploads JSON/results as an artifact.
- Store the dataset version, commit SHA, run configuration and results alongside measured metrics. Never use illustrative numbers from the design references.
